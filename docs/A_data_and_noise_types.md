# A. 데이터 확보·전처리 + 잡음/함정 유형 정의

> 담당 영역: §10-A. 오늘 목표 = 유형을 상상으로 짜지 않고, **ACI-Bench에 이미 있는 잡음은 빼고 없는 것만 자체 제작**하도록 근거를 실측으로 확보.

## A-0. 계획서 대비 정정 사항

`§3-1`은 "MTS-Dialog은 정보가 없으면 `N/A`로 표기 → 미확인 명시 원칙이 이미 채택됨"이라 적고 A를 `(완료)`로 표시했다. **실제 데이터에는 N/A가 0건이다** (라벨 공개 세트 1,301행 전수, 전체값·부분문자열 모두). 재현: `python recon/verify_claims.py` §2.

이유: MTS-Dialog의 1행은 "이 스니펫에 **존재하는** 섹션 하나"만 담는다. 부재를 적을 자리 자체가 없다. 따라서 "미확인 명시"는 물려받는 관행이 아니라 **우리가 새로 도입하는 규약**이고, 이건 기여를 약화가 아니라 강화한다(§B-3, 회의안건 1).

## A-1. 두 데이터셋의 역할 재정의 (실측 근거)

| | MTS-Dialog | ACI-Bench |
|---|---|---|
| 규모 | 1,701 (train 1,201/val 100/test1 200/test2 200) ✓ | 207 (train 67/val 20/test1~3 각 40) ✓ |
| 1행 = | 6턴/63단어 스니펫 → 20헤더 중 1개 → 14단어 요약 | 1,240단어 full-visit 대화 → 415단어 전체 노트 |
| SOAP 노트 생성? | **불가** (1행당 섹션 1개, 4파트 원본 없음) | 가능 (full-visit) |
| 우리 용도 | **보조**: 섹션 매핑·hedge 어휘·정정 패턴의 근거자료 | **주**: SOAP 생성·평가 |

→ 계획서 §5-5의 "MTS-Dialog으로 SOAP 평가"는 성립하지 않음. **ACI-Bench 주 / MTS-Dialog 보조**로 확정(사용자 결정).

## A-2. 잡음(Noise) 유형 — ACI-Bench 실측 빈도 (n=207 대화)

`recon/verify_claims.py` + 별도 측정 결과. **빈도가 높으면 벤치마크에 이미 있음 → 자체 제작 불필요**, 낮으면 자체 제작 가치.

| 잡음 유형 | ACI-Bench 실측 | 판단 |
|---|---|---|
| filler (um/uh/mm-hmm/yeah) | **207/207 (100%)** | 이미 충분 → 자체 제작 불필요 |
| 정정·되묻기 (actually/sorry/i mean) | **155/207 (75%)** | 이미 충분 |
| 발화 끊김 (`--`, `...`) | 65/207 (31%) | 존재하나 보강 여지 |
| 잡담·화제이탈 (weekend/weather/golf) | 52/207 (25%) | 존재 |
| 제3화자 `[patient_guest]` | **5/207 (2%)** | **희소 → 자체 제작 가치** |
| ASR 화자태그 **오류** | ACI는 정제됨 / MTS엔 실제 오타 존재 (`Guest_clinican`, `Gest_family`) | **자체 재현 가치** |

전 대화가 ASR 산출물 스타일임도 확인: 소문자 시작 발화 207/207, 구두점 앞 공백 127/207.

**결론(자체 잡음셋 우선순위)**: ① ASR 화자 오태깅(환자↔의사 뒤바뀜) ② 제3화자(보호자)가 환자 정보를 대신 진술 ③ 시간 순서 뒤섞임 ④ 재질문에 의한 수치 정정 — 이 4종이 벤치마크에 희소하거나 없음. filler·구어체는 굳이 만들 필요 없음(이미 100%).

## A-3. 함정(Adversarial) 유형 — 환각 3종 (계획서 §3-2 유지, 근거 보강)

계획서의 날조/과잉확정/누락회피 3종은 타당. 단 §5-3 채점을 위해 각 케이스에 **음성 라벨**을 붙이는데, 그 채점법이 exact-match면 안 됨(→ C조 §C-2).

- **날조(Fabrication)**: 대화에 없는 사실을 노트에 생성. (예: 대화에 없는 "denies chest pain"을 넣음 — `denies`는 gold note에 184회 나오는 정상 어휘라 더 잘 섞임)
- **과잉확정(Overcommitment)**: hedge 발화("아마 좀…")를 확정("환자는 X이다")으로. → §B-2 hedge 어휘 규칙과 직접 연결.
- **누락회피 실패(Missed omission)**: 대화에 없는 필수항목을 미확인 처리하지 않고 임의로 채움. → S가 88%인 MTS 분포상 O/A/P에서 가장 자주 발생.
