# 노이즈 강건성 평가 결과 (07-20) — 고은 noise100 + 다연 semantic 64쌍

> 재료: 고은 `noise_en_100_main.csv`(형태·구조 노이즈 5유형) + 다연 `aci_semantic_noise_eval_flat_128.csv`(의미 함정 8유형, clean–noisy 쌍).
> 조건: 모델 2종(qwen2.5-7b, qwen2.5-32b) × 단계 4종(baseline/improve2/soap/**soap_hard**) — ACI 본평가와 동일 세팅(greedy, 32B judge).
> 원자료: `outputs/noise_analysis/summary.json`, 상세 위반 내역은 아래 표. 한국어 60건(ko_demo)은 설계대로 시연 전용(정량 제외).

## 1. 다연 — 의미 함정 (clean–noisy 64쌍, label-preserving)

**함정 위반율(FCR) = 함정 명제를 노트에 받아쓴 쌍 / 64.** clean 쌍에 같은 명제를 적용한 대조 실험으로 라벨 충돌(원본 진료 내용과 우연히 겹치는 과광의 명제 3건: not pregnant / dose confirmed / twice daily)을 식별·제외한 **보정값**이 아래 표.

| 모델 | 단계 | 진짜 함정 위반 | HR clean→noisy (Δpp) | R1 변화 |
|---|---|---|---|---|
| qwen7b | baseline | **1/64** (흡연 확정 오기록) | 5.7→6.7 (+1.0) | +0.011 |
| qwen7b | improve2 | 0/64 | 3.6→3.6 (0.0) | +0.016 |
| qwen7b | soap | 0/64 | 2.1→3.2 (+1.1) | −0.011 |
| qwen7b | soap_hard | **1/64** (대장폴립 귀속) | 5.0→3.0 (−2.0) | −0.008 |
| qwen32b | baseline | 0/64 | 2.7→2.6 (−0.1) | −0.001 |
| qwen32b | improve2 | 0/64 | 3.5→2.5 (−1.0) | −0.005 |
| qwen32b | soap | 0/64 | 2.3→1.1 (−1.2) | −0.006 |
| qwen32b | soap_hard | 0/64 | 1.2→1.7 (+0.5) | +0.002 |

**해석**
- v1 함정(잘못된 정보+**명시적 정정** 포함)은 사실상 전 조건 방어 — "모델이 정정 발화를 알아듣는가"의 답은 예. 32B는 noisy에서 HR이 오히려 감소(정정 발화가 모델을 더 보수적으로 만듦). Robustness Drop도 ±0.02 내 = 실질 없음.
- 판별력은 다연님이 이미 계획한 **v2(label-changing·중간 삽입·정정 없는 함정)** 에서 나올 것 — v1 결과가 그 필요성을 실증.
- dev/holdout 분리 결과 일관(누수 없음). holdout 규율 유지 중.

**데이터 QA 피드백(다연님께)**: forbidden_claims 3건이 과광의 → 원본 진료 사실과 충돌(예: "The patient is not pregnant."는 D2N026 원본에서 정당하게 참). 개체 특정형("the unidentified white pill의 용량이 확인됨")으로 좁히면 v2에서 해결. 이번 clean-대조 설계가 이걸 자동으로 걸러줬음.

## 2. 고은 — 형태·구조 노이즈 (100건, 자체 gold)

**여기가 진짜 스트레스 테스트.** ACI(참고: 7B soap 3.0% / 32B soap 1.2%) 대비:

| 모델 | 단계 | 환각률 | R1 |
|---|---|---|---|
| qwen7b | baseline | 16.0% | 0.445 |
| qwen7b | improve2 | 13.3% | **0.520** |
| qwen7b | soap | 14.1% | 0.504 |
| qwen7b | soap_hard | **17.7%** ⚠ | 0.504 |
| qwen32b | baseline | 4.2% | 0.460 |
| qwen32b | improve2 | **4.1%** | **0.593** |
| qwen32b | soap | 5.8% | 0.538 |
| qwen32b | soap_hard | 5.9% | 0.541 |

유형별 환각률(soap 기준, 7B / 32B): 제3화자 0.200/0.140 · 화자오태깅 0.150/0.081 · 시간뒤섞임 0.159/0.018 · 수치정정 0.070/0.000 · ASR숫자 0.101/0.009.

**해석**
1. **모델 크기가 강건성의 지배 요인**: 7B는 ACI 대비 환각 4~6배 폭증(13~18%), 32B는 4~6%로 선방. 수치정정·ASR숫자는 32B가 사실상 완벽(0~1%).
2. **S/O/A/P 규격의 부작용 발견**: 32B가 baseline 4.2% < soap 5.8% — 구역을 채워야 한다는 압력이 짧은 대화에서 **A/P 보일러플레이트 날조**("Monitor symptoms closely", "Follow up if symptoms persist")를 유발. 플래그된 문장 대부분이 이 부류(제3화자 유형의 0.140도 대부분 보일러플레이트, 보호자 귀속 오류가 아님). 고은 gold가 A/P를 미확인 처리한 설계와 정확히 충돌하는 지점 = **[미확인] 규칙이 A/P에서 안 먹히는 실증**.
3. **soap_hard(노이즈 대응 규칙 추가)는 역효과**: 7B에서 최악(17.7%+진짜 함정 위반 1건), 32B에서도 이득 없음. 규칙을 더 얹는 방식은 답이 아님 — 특히 소형모델은 규칙 과적재에 취약.

## 3. 종합 결론 · 다음 프롬프트 수정 타깃

- **노이즈 상황 추천 조합 = 32B × improve2** (R1 0.593 최고, HR 4.1%, FCR 0). clean 표준 상황에선 기존 결론(32B × soap) 유지 — "규격의 구역 채움 압력"이 노이즈에서 비용이 됨.
- **프롬프트 수정 1순위**(다연님 "추가 수정" 요청의 구체 타깃): soap 프롬프트의 A/P **[미확인] 강제를 강화** — "대화에 plan 논의가 없으면 표준 권고를 쓰지 말고 [미확인]" 규칙을 A/P 전용으로 명시 → 고은 데이터로 재평가(가장 잘 드러나는 테스트베드).
- soap_hard는 폐기 또는 재설계(규칙 추가가 아니라 예시 기반 few-shot 등).
- 검증 레이어(judge) 관점: 노이즈 상황에서도 판정 파이프라인 자체는 건전(파싱 실패 0). 보일러플레이트 환각을 정확히 잡는 것이 확인됨 — 웹 데모 골든케이스와 일치.

*평가 이력 주: 고은 데이터의 보호자(guest) 화자 분리 매핑을 반영해 전 조건을 동일 전처리로 재생성 후 채점(일관성 보장). 함정 위반 판정은 32B entailment, 병렬 실행.*
